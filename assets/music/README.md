# Фоновая музыка / Background music

Тихие инструментальные мелодии для приложения «Шорашим». Все треки выровнены примерно на −20 LUFS, чтобы смена не давала скачка громкости.

В `manifest.json` поле `title` — название для экрана (по-русски), `grokTitle` — исходное название в Grok Imagine. Чтобы добавить трек, положите файл `.ogg` (Vorbis, примерно 128–160 кбит/с) в эту папку и допишите его в манифест. Пересобирать программу не нужно.

Tracks generated with Grok Imagine.
