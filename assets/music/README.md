# Фоновая музыка / Background music

Тихие инструментальные мелодии для приложения «Шорашим».

Чтобы добавить трек, положите файл `.ogg` (Vorbis, примерно 128–160 кбит/с) в эту папку и допишите его в `manifest.json`. Пересобирать программу не нужно: список читается из манифеста при запуске.

Tracks generated with Grok Imagine.
